Why I'm Doing This

I moved to Park La Brea and found a group that's been fighting for residents since 1943. But it's shrinking — not because the work isn't good, but because nobody can see it. I have the skills to fix that. I built the tools. I built the system. But a system only works if people run it. I'm not asking for donations or dues. I'm asking for your time — a few hours a month — to help build something that makes this place better for everyone who lives here.
